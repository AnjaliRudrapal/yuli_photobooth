# Yuli PhotoBooth

A browser-based photo booth that lets users capture three photos, create a collage, apply filters, and download the final result as a PNG.

## Features

- 📷 Browser camera access
- 🔄 Mirror mode
- ⏱️ 3-second countdown
- 📸 Capture 3 photos
- 🎨 Multiple photo filters
- 🖼️ 3 collage layouts
- 💾 PNG download
- 🖨️ Print collage
- 📱 Responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- MediaDevices API
- Canvas API
